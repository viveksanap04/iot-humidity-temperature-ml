
# IoT Humidity and Temperature Monitoring with Machine Learning

## Project Overview
An IoT-based project that collects real-time temperature and humidity data using ESP32 and DHT22 sensors.

The collected data is stored in Firebase and used for Machine Learning and Deep Learning experiments.

## Technologies Used
- Python
- ESP32
- DHT22 Sensor
- Firebase Realtime Database
- Machine Learning
- Deep Learning
- TensorFlow
- Scikit-learn

## Project Objectives
- Monitor real-time temperature and humidity.
- Store sensor readings in Firebase.
- Collect historical datasets.
- Perform data analysis.
- Predict temperature and humidity using ML and DNN models.
